# zed-claude-code-acp-doctor
Zed sometimes do drama and pretend like claude code is not there, I made a script with claude code to end that

```bash
chmod +x zed-claude-doctor.sh
./zed-claude-doctor.sh           # diagnose only
./zed-claude-doctor.sh --fix     # apply fixes with confirmation per step
./zed-claude-doctor.sh --fix -y  # apply everything without prompting
./zed-claude-doctor.sh -v        # verbose
```
